## About

The IBM Data Science Professional Certificate is a 12-course program covering the full data science workflow: collecting and cleaning data, analyzing and visualizing it, building machine learning models, and communicating results. It is beginner-level and requires no prior programming experience.

## Key Takeaways

- **Data science is a process, not just modeling.** Using the CRISP-DM methodology taught me that understanding the business problem and preparing the data come before any algorithm, and that most of the work happens at those stages.
- **Clean data matters more than complex models.** Handling missing values, fixing inconsistent formats, normalizing, and binning had a bigger effect on results than switching algorithms.
- **SQL and Python work best together.** I learned to query relational databases with SQL (joins, views, stored procedures) and to analyze the results in Python with Pandas and NumPy.
- **Visualization is how you communicate findings.** Building charts with Matplotlib and Seaborn, maps with Folium, and interactive dashboards with Plotly and Dash showed me how to turn analysis into a story that others can understand.
- **Model evaluation is as important as model building.** I practiced comparing regression, classification, and clustering models using appropriate metrics and validation strategies, rather than trusting a single accuracy score.
- **Reproducible work needs good tooling.** Using Jupyter notebooks, Git, and GitHub taught me to document and version my work so that others can follow and reproduce it.
- **Generative AI can speed up data work.** I explored how AI tools can help with querying data, generating datasets, and refining models, while still needing human judgment and attention to data ethics.
